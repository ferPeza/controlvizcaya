# Pase de Baño

Control de salidas al baño por profesor y grupo.

**Stack:** React + TypeScript + Vite · CSS Modules · Supabase (Postgres)

## Desarrollo
```bash
npm install
npm run dev
```

## Producción
```bash
npm run build   # genera dist/
```
Deploy en Vercel (Framework Preset: Vite).

## Base de datos (Supabase)
Tablas: `bano_profesores`, `bano_grupos`, `bano_alumnos`, `bano_registros`, `bano_profesor_grupos`.
